# Mini Playbox

轻量小游戏门户，前端使用 React + Vite + TypeScript，后端使用 Node.js 内置模块，数据库使用 SQLite。

## 目录

```text
mini-playbox/
├── frontend/       # React 前端
├── backend/        # Node + SQLite 后端
└── README.md
```

## 启动

后端：

```bash
cd backend
node server.mjs
```

前端开发：

```bash
cd frontend
pnpm install
pnpm dev
```

生产构建：

```bash
cd frontend
pnpm build
```
