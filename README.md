## ✨ 项目简介

Mini Playbox 是一个面向博客/个人站点嵌入的独立小游戏服务前端。当前处于 **UI/交互设计阶段**，目标是打造一个视觉精致、操作流畅、无需注册即可游玩的轻量游戏门户。

> 🚧 **注意**：本仓库目前仅包含前端静态页面设计，游戏逻辑和后端服务将在后续阶段逐步实现。

---

## 🎯 设计理念

| 关键词 | 说明 |
|--------|------|
| **轻量** | 纯静态页面，零依赖加载，首屏秒开 |
| **精致** | 玻璃拟态风格 + 微动效，视觉体验上乘 |
| **碎片化** | 单局 2-10 分钟，适配地铁、午休等场景 |
| **无门槛** | 无需登录、无需下载，点击即玩 |
| **可嵌入** | 设计为可独立部署，也可嵌入现有博客站点 |

### 交互组件

- **游戏详情弹窗**: 点击卡片弹出游戏介绍 + 开始按钮
- **试玩模式**: 内置记忆翻牌 Demo，可体验步数/配对统计
- **收藏系统**: 本地收藏喜欢的游戏（后续接入云同步）
- **明暗主题**: 一键切换浅色 / 深色模式
- **响应式布局**: 适配手机、平板、桌面三端

---

## 🎨 设计风格

- **视觉**: Glassmorphism（玻璃拟态）+ 卡片半透明叠加
- **配色**: 明亮渐变 + 柔和阴影，确保文字可读性
- **动效**: 卡片悬浮微位移、按钮缩放反馈、Hero 无缝轮播
- **图标**: 纯 SVG 线性图标，统一 24×24 规格

## 🚀 快速开始

### 本地预览

由于是纯静态页面，任意静态服务器都可运行：

```bash
# 方式一：Python 内置服务器
python -m http.server 8080

# 方式二：Node.js (需全局安装 serve)
npx serve .

# 方式三：直接双击 index.html（部分浏览器对 fetch/file:// 有局限）
```

然后在浏览器打开 `http://localhost:8080` 即可。

### 生成占位封面

如需重新生成 Mock 封面图（需 Python + Pillow）：

```bash
pip install Pillow
python generate_assets.py
```
