## 产品概述

「保卫阿斗」的**主菜单/练兵场**界面：玩家从 `GameStartScreen` 的"进入练兵场"按钮进入后，看到一座 2D 横向营寨场景，9 名武将分散站立、随机走动、偶尔文字互动；左侧固定菜单提供「开始 / 军械库 / 远征 / 设置」四个入口（**仅「开始」实装，其它显示「敬请期待」浮层**）；点击武将弹出侧拉信息卡。本界面是后续远征模式、军械库内部、剧情对话等所有 PvE 模块的**总枢纽**，本期只交付主界面骨架与视觉，所有数据来自前端 mock。

## 核心功能

- 路由与入口：`#/training-ground` hash 路由 + `GameStartScreen` 按钮
- 左侧固定菜单：4 个菜单项，点击切换右侧内容区（仅「开始」跳转游戏，其它显示「敬请期待」浮层）
- 主舞台：背景图 + 9 名武将立绘，按预设站位布局
- 武将互动：呼吸 / 随机走动 / 点头 / 文字气泡（静态立绘 + 文字走位）
- 武将详情：点击武将弹出侧拉卡（基础信息 + 默认武器）
- 视差：背景随鼠标轻微平移
- 状态条：顶部账号 / 当前章节 / 返回门户，底部 BGM 状态
- 菜单占位：军械库 / 远征 / 设置 点击显示「敬请期待」半透明浮层

## 本期边界

### 关键设计决策

1. **模块边界**：`training/` 与 `inventory/`、`heroes/` 解耦；本期不依赖 inventory/heroes，未来再桥接
2. **武将位置**：`layout.ts` 用坐标表（x/y）描述每个武将，组件按数据驱动渲染
3. **资源加载**：武将立绘用 `<img>`，避免 Phaser 依赖；立绘 `onerror` 回退 emoji 头像
4. **动效统一**：

- 呼吸：`@keyframes breathe { 0%,100%{scale:1} 50%{scale:1.02} }`，4s 循环
- 走动：`@keyframes wander` 配合 CSS variables `--tx/--ty`，8-12s 随机
- 说话：scale 1.05 + 0.3s 弹性回弹，气泡 fade-in

5. **视差**：监听 mousemove，按比例 translate 背景层（max ±10px）
6. **菜单占位**：`ComingSoonOverlay` 通过 Zustand `activeMenu` 状态控制

## 整体风格

暗色军旅 / 冷调 / 烛火摇曳 / 静态立绘 + 文字走位。整体是一个 16:9 的横向营寨舞台，左侧 240px 固定菜单，其余宽度给舞台。武将按 z-index 在舞台中前后分层（z=前景 / 1=中景 / 2=后景）。

## 6 个区块（单页）

1. **顶部状态栏**（高 56px，fixed）

- 左侧：返回门户按钮
- 中间：当前章节"长坂坡·新野" + 副标题
- 右侧：账号头像 + displayName + 货币占位（铜钱图标 + ---）

2. **左侧固定菜单**（宽 240px，fixed）

- 4 个按钮纵向排列：开始（实装）/ 军械库 / 远征 / 设置
- 当前选中按钮左侧 3px 金色边 + 内部浅金背景
- hover：背景 #2a2f37 + 微光描边
- 底部：版本号 + 制作组

3. **主舞台**（占满右侧）

- 背景层：3-4 张候选背景图之一（横向营寨，1.6:1），parallax 视差
- 中景：营帐 / 火盆 / 栅栏 / 训练木桩
- 9 武将立绘按 z-index 分层渲染，前景 3 人、中景 3 人、后景 3 人
- 武将动效：呼吸（持续）+ 走动（每 8-12s 触发）+ 文字气泡（每 10-20s 随机）

4. **武将详情侧拉卡**（点击武将时滑出，宽 360px）

- 顶部：武将立绘大图 + 名字（稀有度色）+ 等级
- 中部：基础属性（HP/伤害/CD）
- 底部：默认武器卡 + 持有/装备状态
- 关闭按钮：右上角 X

5. **底部信息条**（高 40px，fixed）

- 左：BGM 状态（播放/暂停图标 + 曲名）
- 中：操作提示"点击武将查看详情 · 点击菜单切换场景"
- 右：当前时间 / 在线状态

6. **「敬请期待」浮层**（点击非「开始」时显示）

- 半透明黑底（#000000aa）
- 中央：图标 + "敬请期待" + "该模块正在筹备中" + 关闭按钮
- 0.3s fade + scale 入场
